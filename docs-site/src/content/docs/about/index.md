Joinery is an MIT-licensed desktop database workbench for SQL Server, PostgreSQL and MySQL,
built with Electron and React. It is a fork of
[MemberJunction/Forge](https://github.com/MemberJunction/Forge).

## These docs

This site is the user documentation. It covers installing Joinery, connecting to a database, and
using the app. It is deliberately **not** a second copy of the developer documentation, which
stays in the repository:

- [`CONTRIBUTING.md`](https://github.com/cadam11/joinery/blob/main/CONTRIBUTING.md) — development
  setup, commit conventions, the PR process, and the code-style rules.
- [`docs/ARCHITECTURE.md`](https://github.com/cadam11/joinery/blob/main/docs/ARCHITECTURE.md) —
  the process model, the IPC boundary, and the multi-engine SQL layer.
- [`docs/brand/`](https://github.com/cadam11/joinery/tree/main/docs/brand) — the brand kit: the
  mark, the lockups, the palette, the typefaces, and the usage rules. Both the app and this site
  are built from those tokens.

## Releases

Every release, with its notes and its installers, is on
[GitHub Releases](https://github.com/cadam11/joinery/releases). **v1.0.0** (3 September 2026) is
the first. See [Install](../getting-started/install/) for the Homebrew command, the direct
downloads, and building from source.
